# Outcome

A workflow adapter can submit bounded Codex PR-review findings and receive immutable structured evidence showing that every applicable finding was resolved, disputed with evidence, or escalated.

# Why now

This delivers AC-008 from `docs/PRODUCT.md` after explicit QA evidence and establishes the review-disposition gate needed before merge and production gates are added.

# Required context

- `docs/PRODUCT.md` — AC-008 acceptance and MVP boundaries.
- `docs/WORKFLOW.md` — Codex PR-review phase and finding-disposition rules.
- `docs/ARCHITECTURE.md` — adapter, evidence, and local-first boundaries.
- `docs/SECURITY.md` — untrusted review content and bounded evidence.
- `SYSTEM.md` — current implementation baseline.

# Scope

## In

- Add a reusable Codex PR-review phase runner for a bounded ordered finding set.
- Require every finding to receive exactly one resolved, evidenced-dispute, or escalated disposition.
- Return immutable structured evidence for every attempted finding and an overall passed, blocked, or failed outcome.
- Allow a successful empty review without invoking a finding adapter.
- Fail closed on malformed findings/results or callback failures and cover behavior deterministically.

## Out

- GitHub/Codex API polling, authentication, comment mutation, PR creation, CI, merge, deployment, or durable artifact persistence.
- Automatically deciding whether a review finding is valid or authorizing an unresolved finding.
- Integration with AC-006 fix loops, AC-007 QA, or later durable orchestration.

# Implementation constraints

- Review findings and adapter results are untrusted data and must be copied, validated, bounded, and never treated as instructions.
- Finding identifiers are unique and stable within a review; at most 64 findings may be evaluated.
- A dispute requires at least one bounded evidence reference; escalation blocks passage without being converted to success.
- Callback exceptions do not leak exception details; malformed results fail closed.
- Returned findings, dispositions, and reference arrays are deeply immutable.
- Implement only from `feat/AC-008-codex-pr-review` in its isolated worktree.
